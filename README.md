# LOF 溢价监控（在线预览）

面向访客的公开预览站点：一眼看清 LOF 溢价、QDII 跟盘与市场资讯。

## 在线访问

- **站点**：<https://eikeitsu.github.io/lof-monitor-preview/#/>
- **功能说明**：<https://eikeitsu.github.io/lof-monitor-preview/docs/guide/user-guide.html>

## 能看什么

| 模块      | 说明                                       |
| --------- | ------------------------------------------ |
| 最新报告  | A 股 LOF 场内溢价 / 折价一览               |
| QDII 跟盘 | 美股 / 亚太场外估值与指数区                |
| 行情      | 大盘指数、实时溢价、债市、股债利差、板块榜 |
| 资讯      | 市场快讯时间轴、只读社区动态               |
| 历史      | 往期报告快照回溯                           |

数据仅供参考，不构成投资建议。
